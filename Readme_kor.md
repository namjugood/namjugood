## 🧭 소개

웹 개발 4년차 백엔드 개발자입니다. 주로 금융권 SI 프로젝트에서 Spring 기반 백엔드 시스템을 구축해왔으며, 비즈니스 로직에 대한 협의를 원활하게 이끌어갈 수 있습니다. 최근에는 Django와 React로 스택을 넓혀가고 있고, Cursor AI를 활용한 AI 기반 개발에도 관심을 갖고 프로젝트를 진행 중입니다.

- 🔭 현재 진행 중: 금융권 SI 프로젝트의 Spring 기반 백엔드 시스템
- 🌱 현재 학습 중: Django, React, Cursor AI를 활용한 AI 기반 개발
- 👯 협업하고 싶은 분야: 백엔드 아키텍처 및 Spring 기반 프로젝트
- 💬 이런 주제로 이야기해요: Java, Spring, Spring Boot, 백엔드 아키텍처
