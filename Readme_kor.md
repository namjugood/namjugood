금융권 디지털 채널 구축과 운영에 전문성을 보유한 백엔드 개발자입니다. 흔들림 없는 안정성에 안주하지 않고, 최신 AI 인프라 탐구와 SaaS 개발로 기술 영역을 주도적으로 확장하고 있습니다.

- 🔭 **현재 진행 중** — 오케이캐피탈 및 계열사 디지털 채널 서비스 운영·유지보수, AI/RPA 기반 업무 자동화
- 🌱 **현재 탐구 중** — Dify 기반 AI 에이전트, 로컬 LLM 환경 구축, ComfyUI 멀티모달 실험
- 🚀 **사이드 프로젝트** — [sirow](http://sirow.app), 일반인이 코딩 없이 웹훅 데이터를 수집할 수 있는 SaaS를 기획부터 풀스택 개발까지 단독 론칭
- 💬 **강점** — 유관 부서(인프라·보안·계정계 등) 실무진과의 활발한 소통을 바탕으로 신속한 장애 대응과 업무 조율
- 📫 **연락처** — namjugood@gmail.com
